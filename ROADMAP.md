# Forgewise roadmap

This roadmap is intentionally small. It tracks the next useful slices without pretending the project already has reviewed engineering content.

## Now

- Keep the static scaffold buildable with `npm run check`.
- Review and merge the scaffold branch.
- Decide the software code license separately from editorial CC BY-SA 4.0.
- Publish the generated static site only after the scaffold is reviewed.

## Next

- Add one reviewed pilot article from `content/templates/article-template.md`.
- Add the matching formula block only when the formula source and unit assumptions are verified.
- Add a lightweight article index once more than one article exists.
- Add one more language only when a human-maintained translation exists.

## Later

- Add search when article count makes navigation annoying.
- Add a formula calculator only after formula blocks are reviewed enough to justify executable logic.
- Add source/reference tooling only if manual review becomes the bottleneck.
- Add richer publishing automation only if GitHub Pages/static hosting needs it.

## Not planned yet

- No generated technical claims.
- No automatic translation.
- No interactive calculator before reviewed formula data exists.
- No Roloff/Matek-derived content unless material is provided and the use is documented.
