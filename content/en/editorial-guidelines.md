# Editorial guidelines

## Target levels

- Lay readers: intuitive explanation without hidden prerequisites.
- Students: traceable formulas, symbols, units, and assumptions.
- Practicing engineers: derivations, limits, design rules, and open uncertainties.

## Article structure

Use `content/templates/article-template.md` without reordering sections.

## Writing and derivation

- Write original explanations for Forgewise.
- Do not copy textbook, standard, image, table, or diagram content unless its license and attribution are checked.
- Mark unresolved questions and technical uncertainty directly in the article.

## Sources

- Cite the source for formulas, assumptions, and data.
- Do not use unverified sources, invented values, or claimed checks.
- Roloff/Matek was not used for this scaffold. Later technical review with provided material can be documented when it actually happens.

## Standards and material values

- Name standards only when verified; do not reproduce standard text or large standard tables.
- Treat material properties as guide values unless a cited datasheet or standard says otherwise.
- Point readers to current datasheets for design decisions.

## Licensing

Editorial content is intended for CC BY-SA 4.0. Software code may use a different license; no code license has been chosen in this repository yet.
